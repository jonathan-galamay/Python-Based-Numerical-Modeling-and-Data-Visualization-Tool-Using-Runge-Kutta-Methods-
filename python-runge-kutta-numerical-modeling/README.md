# Python-Based Numerical Modeling and Data Visualization Tool Using Runge-Kutta Methods

A Python-based numerical modeling and data visualization program that solves first-order ordinary differential equations (ODEs) using Runge-Kutta methods of first through fourth order.

The program compares the numerical solutions produced by **RK1 (Euler), RK2, RK3, and RK4** against an available exact analytical solution and visualizes their behavior in real time using Matplotlib.

## Features

- RK1 (Euler), RK2, RK3, and RK4 numerical methods
- Multiple predefined first-order ODEs
- User-defined/custom derivative functions
- User-defined exact solutions for custom equations
- Real-time plotting of numerical approximations
- Comparison with exact analytical solutions
- Automatic y-axis adjustment during visualization
- Input validation for numerical parameters
- Mathematical functions including `sin`, `cos`, `tan`, `exp`, `log`, and `sqrt`

## Supported Equations

The program currently includes:

| Option | Differential Equation | Exact Solution |
|---|---|---|
| 1 | `y' = sin(x)` | `y0 + 1 - cos(x)` |
| 2 | `y' = cos(x)` | `y0 + sin(x)` |
| 3 | `y' = exp(x)` | `y0 + exp(x) - 1` |
| 4 | `y' = log(x+1)` | `y0 + (x+1)log(x+1) - x` |
| 5 | `y' = x^2` | `y0 + x^3/3` |
| 6 | `y' = 1/(1+x^2)` | `y0 + arctan(x)` |
| 7 | `y' = x + y` | `(y0 + 1)exp(x) - x - 1` |
| 8 | `y' = y - x^2 + 1` | `x^2 + 2x + 1 + (y0 - 1)exp(x)` |
| 9 | `y' = x*y` | `y0 * exp(x^2/2)` |
| 10 | `y' = sin(x) + y` | `(y0 + 1/2)exp(x) - (sin(x) + cos(x))/2` |
| 11 | Custom | User-provided |

Clone the repository:

```bash

cd python-runge-kutta-numerical-modeling
```

Create and activate a virtual environment if desired:

### Windows PowerShell

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Usage

Run the program:

```bash
python runge_kutta_visualizer.py
```

The program will ask for:

1. The differential equation to solve
2. Step size `h`
3. Final x-value
4. Initial condition `y(0)`

For option 11, you can enter a custom derivative function and its exact solution.

### Example

For:

```text
y' = x + y
```

you can select:

```text
7
```

Then provide values such as:

```text
Enter step size h: 0.1
Enter final x-value: 5
Enter initial value y(0): 1
```

The program will display the numerical approximations generated by RK1, RK2, RK3, and RK4 alongside the exact solution.

## Custom Functions

The custom-function feature accepts mathematical expressions using the variables `x`, `y`, and `y0`.

Available functions include:

```text
sin(x)
cos(x)
tan(x)
exp(x)
log(x)
sqrt(x)
pi
np
```

Example derivative:

```text
x + y
```

Example exact solution:

```text
2*exp(x) - x - 1
```

> **Note:** The custom-function feature uses Python's `eval()` with built-ins disabled. Only enter mathematical expressions you understand and trust. Do not use this feature to execute arbitrary or untrusted code.

## Numerical Methods

The program implements the standard explicit Runge-Kutta methods:

### RK1 — Euler Method

First-order approximation:

```text
y(n+1) = y(n) + h f(x(n), y(n))
```

### RK2 — Second-Order Runge-Kutta

The implementation uses the midpoint formulation:

```text
k1 = h f(x, y)
k2 = h f(x + h/2, y + k1/2)

y(new) = y + k2
```

### RK3 — Third-Order Runge-Kutta

```text
k1 = h f(x, y)
k2 = h f(x + h/2, y + k1/2)
k3 = h f(x + h, y - k1 + 2k2)

y(new) = y + (k1 + 4k2 + k3)/6
```

### RK4 — Classical Fourth-Order Runge-Kutta

```text
k1 = h f(x, y)
k2 = h f(x + h/2, y + k1/2)
k3 = h f(x + h/2, y + k2/2)
k4 = h f(x + h, y + k3)

y(new) = y + (k1 + 2k2 + 2k3 + k4)/6
```
